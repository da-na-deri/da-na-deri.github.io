`ECMLE` is an R package for the **Elliptical Covering Marginal Likelihood Estimator**.
It implements a geometric marginal-likelihood estimator based on posterior draws,
log-posterior evaluations, and ellipsoidal coverings of a high-posterior-density region.

The method is described in

> Naderi, D., Robert, C. P., Kamary, K., & Wraith, D. (2026).
> *Approximating evidence via bounded harmonic means.*
> Statistics and Computing, 36(3), article 120.
> [doi:10.1007/s11222-026-10875-z](https://doi.org/10.1007/s11222-026-10875-z) ·
> [arXiv:2510.20617](https://arxiv.org/abs/2510.20617)

## Why

Bayesian model comparison needs the evidence $Z = \int p(y \mid \theta)\, \pi(\theta)\, d\theta$.
The harmonic mean estimator of Newton and Raftery (1994) is simple but can have infinite
variance. ECMLE follows Gelfand and Dey (1994) and Robert and Wraith (2009) by using an
indicator of a high posterior density (HPD) region as the instrumental function, and
covers that region with non-overlapping ellipsoids so that its volume can be computed
exactly. The resulting estimator has finite variance and works for multimodal posteriors.

## Installation

```r
install.packages("ECMLE")
```

## Main function

```r
ecmle(post_samples, lps, log_post_fn, hpd_level = 0.75)
```

- `post_samples`: matrix of posterior draws, one row per draw.
- `lps`: numeric vector of log-posterior values at `post_samples`.
- `log_post_fn`: function returning the log unnormalised posterior density at a parameter vector.
- `hpd_level`: HPD fraction used to define the covered region.

## Minimal example

```r
set.seed(1)
post_samples <- cbind(rnorm(400), rnorm(400))
lps <- apply(post_samples, 1, function(z) sum(dnorm(z, log = TRUE)))
log_post_fn <- function(theta) sum(dnorm(theta, log = TRUE))

fit <- ecmle(post_samples, lps, log_post_fn, hpd_level = 0.75)
print(fit)
plot(fit)
```

## Package contents

- `ecmle()`: estimates the log marginal likelihood.
- `summary()`, `plot()`: compact summary and running-estimate plot.
- `plot_ecmle_2d()`, `draw_ellipse_2d()`: 2-D visualisation of the fitted ellipsoids.
- `pair_plot()`: pair plot for posterior sample matrices.
- `rosenbrock_*()`: Rosenbrock ("banana") posterior benchmark functions.
